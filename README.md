# Simple Pong

A small, single-file browser Pong game using HTML, CSS and JavaScript. The left paddle is controlled by the player (mouse or arrow keys), the right paddle is a simple AI.

How to run:
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Click "Start / Restart" and play.

Controls: Move the left paddle with your mouse or use the Up/Down arrow keys.
